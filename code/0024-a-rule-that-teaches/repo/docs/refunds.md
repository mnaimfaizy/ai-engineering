# Refunds

Decided by billing on 2026-09-14. Before that this lived in a chat thread, where no agent could read it.

- Annual plans refund pro rata by whole months remaining.
- Monthly plans do not refund.
- A plan whose year is used up does not refund.

| Invoice | Plan    | Price | Months left | Refund |
| ------- | ------- | ----- | ----------- | ------ |
| INV-441 | annual  | 120   | 6           | 60     |
| INV-502 | annual  | 120   | 3           | 30     |
| INV-808 | monthly | 15    | n/a         | none   |

One refund per invoice.
