How it works

  • Go in order. Each lesson builds on the one before. Every page ends with links to the previous and next lesson.
  • Pass the check. Each lesson ends with a short quiz. Pass it and the lesson is marked done. You can also mark a lesson done yourself.
  • Progress stays in this browser. Nothing is sent anywhere. To move to another device, download your progress below and load it there.
  • Three lessons have code. 0021, 0023 and 0024 are TypeScript exercises that run locally against a scripted model, using Node 22 or later. No API key and nothing to install.
