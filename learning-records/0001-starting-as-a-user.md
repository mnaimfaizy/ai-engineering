# Starting as a ChatGPT/Claude user, not an API builder

The learner has conversational fluency with assistants and no experience calling LLM APIs, counting tokens, or wiring tools. That sets the floor: lesson 1 must not assume Python, embeddings, RAG, or agent frameworks. The first durable skill is seeing that the model consumes a budget of tokens and emits the next one — because every later pattern (context, loops, graphs, skills) is a way of spending that budget on purpose.
