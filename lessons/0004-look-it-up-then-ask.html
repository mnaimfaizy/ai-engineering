Context trick

Look it up, then ask

The model’s training is a frozen cookbook. Your live menu is not in there. RAG means: find a few pages, paste them into the script, then pack · read · pick as usual.

  1. 1 · FindSearch the library. Keep two or three pages, not the shelf.
  2. 2 · PasteDrop those pages into the user (or system) bubble.
  3. 3 · PickSame call as lesson 0003. The model now “read” the pages.

Find · paste · pick. If the answer already fits in the script, skip the library.

Why a library at all?

Lewis et al. split memory in two: facts baked into the weights, and a pile of documents you can look up and swap when the world changes. That lookup-plus-generate recipe is what they named RAG. Retrieval-Augmented Generation (2020)

Anthropic’s one-line version of how people use it today: retrieve the relevant bits, append them to the prompt. The knowledge base can be huge; the window stays small. Contextual Retrieval

Karpathy’s picture: window = RAM, files = disk. RAG is paging a few files into RAM — not buying a bigger brain.
