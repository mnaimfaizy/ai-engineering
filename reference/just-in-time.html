Just-in-time files

From lesson 0010. Hold a pointer. Load the page this turn. The corpus stays on disk.

  1. PointerPath, query, or URL. Cheap. Not the dump.
  2. NavigateGlob = names. Grep = lines inside. Folder names are signal.
  3. LoadRead (or head/tail) this turn. Propose · run · paste.

Not

  • Not RAG (you find, then paste, then one call). RAG card.
  • Not a skill (a chapter you wrote). Skills card.
  • Not stuffing the repo. A hybrid always-on file (CLAUDE.md) is a cheap note, not the shelf.
  • Sub-agents: a helper’s clean window, a summary back. Sub-agents card.
