Plugins

From lesson 0017. A plugin is how the floor arrives. Not a new model.

  1. BundleManifest + skills / MCP / (Cursor) hooks.
  2. ArriveInstall: user, project, team marketplace.
  3. TrustReviewed marketplace. Then Guard and evals still on.

Not

  • Not a skill — that is the folder inside. Skills card.
  • Not a Slack zip. Official marketplace plugins are reviewed.
  • Not a replacement for Guide · Guard · Job. Team floor.
  • Secrets are variable names, not values in git. Agent security.
  • Agent Plugins = portable skills+MCP. Cursor Plugins add rules, agents, hooks, variables.

Cursor: spec-conformant Agent Plugins load as-is. Live key values stay in the dashboard, not git.
