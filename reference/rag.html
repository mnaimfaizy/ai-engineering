Cheat sheet

RAG

From lesson 0004. Lookup memory, then the same call as 0003.

  1. FindSearch the library. Keep a few snippets.
  2. PastePut them in the script (usually the user bubble).
  3. PickPack · read · pick as before.

When

  • Do: private or changing facts bigger than RAM.
  • Skip: already in the script, or a tiny general question.
  • Don’t dump the shelf — U-curve (lesson 0002).

Lewis et al. 2020 named it; Anthropic: retrieve, append to the prompt. Cousin: just-in-time — the agent navigates during the loop instead of you pasting first.
