Skills

From lesson 0008. A folder, not a second model. Catalog in RAM; chapter on a match.

  1. Catalogname + description. Always in the system prompt.
  2. ChapterSKILL.md body. Loaded when the task matches.
  3. AppendixExtra files or scripts. Only if pointed at.

Not

  • Not a tool (that is a slip you run). Not RAG (pages you found).
  • Not a plugin store — that is how the folder arrives. Plugins card. Not compaction — that is evict · compact · note.
  • Loading the chapter is still propose · run · paste: the slip is read(SKILL.md).
  • The description must say what and when — or the chapter never opens.
  • On a team: a skill in git is a Job (or a chapter of the Guide). Team floor card.
