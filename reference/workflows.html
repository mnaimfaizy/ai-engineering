Workflow vs agent

From lesson 0006. You are writing the program. The model is a function you call.

  1. One callMessages in, text out. Often enough.
  2. WorkflowControl flow is in your source. Predefined path.
  3. AgentYour source is a loop. The model picks the next tool until stop.

Not

  • Not a ChatGPT feature named “Agent Workflow.”
  • Not training a model. Not the harness (allow / run / stop / show) — that card.
  • “Building an agent” = writing that while-loop + tool runner + stop.
  • Need both paths and holes? Graph engineering card.

Anthropic: both are agentic systems. Start with the simplest program that works. Later rungs: stack choice.
